# TaskMaster Pro User Manual

## Getting Started
1. Log in with your assigned credentials.
2. Use the navigation bar to access dashboards, projects, tasks, and analytics.

## Roles
- **Super Admin:** Manage users, projects, and analytics.
- **Project Manager:** Create projects and tasks, oversee team workload.
- **Team Member:** Track assigned tasks and update progress.
- **Client Observer:** View shared project updates.

## Authentication
- Register a new organization from the registration page.
- Reset your password from the "Forgot password" link.

## Dashboards
- Role-based dashboards provide quick stats and links to key actions.

## Projects & Tasks
- Create projects with key dates and team assignments.
- Assign tasks, set priorities, and track status.

## Security Tips
- Use strong passwords and keep credentials secure.
- Log out after completing work on shared machines.
